## 2. 商品ごとの重量（仮）

`src/data/products.ts` の各商品に以下の2項目を追加しています。

- `servingSize`: 1食分の重量（g）
- `packagingWeight`: 箱詰め時の1単位あたり重量（容器込み、g）
- `packagingWeightProvisional: true`: 実測値ではなく仮値であるフラグ

## 4. 注意事項

- 重量はすべて「未開封の小袋／瓶」を前提とした**推定値**です。実測してから
  `products.ts` の `packagingWeight` と `packagingWeightProvisional` を更新してください。
- 送料のUSD換算は固定150円/USDです。実運用では当日のレート（または決済・配送
  システムの実レート）に置き換えてください。
- 2026-06-01 より「国際eパケットライト」は「国際エアパケット」へ名称変更されています。
